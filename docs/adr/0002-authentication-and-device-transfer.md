# 로그인과 기기 이전

상태: accepted (2026-11-21)

영수증을 공유하는 순간에는 캡처부터 할 수 있어야 한다. 여행방은 기기를 바꾼 뒤에도 같은 일행, 증빙, 송금표를 보여줘야 한다.

## 로그인

- 로그인 전에도 사진을 받아 기기에 초안을 저장한다. 여행방을 만들거나 초대를 수락할 때 로그인한다. 로그인 후 열었던 초대로 돌아간다.
- iOS는 Apple과 Google 로그인을 제공한다. Android는 Google 로그인을 제공한다. 로그인 화면에는 소셜 로그인만 제공한다. 이메일 일회용 코드는 두 플랫폼에서 기기 이전과 계정 복구에 사용한다.
- 여행방 구성원 정보, 공유 증빙, 정산 기록과 향후 서비스 이용 권한은 로그인 제공자의 이메일 주소 대신 노나노나 계정 ID로 연결한다.

## 기기 이전

- Apple로 가입한 사용자가 Android에서 Google로 처음 로그인하면 **기존 데이터 가져오기**를 선택할 수 있다.
- 기존 iPhone에서 이전을 승인하거나, 기존 계정에 미리 등록하고 인증한 복구 이메일로 기존 계정 소유를 확인한다. 확인 후 Google 로그인을 기존 노나노나 계정에 연결한다.
- 첫 버전은 새 Android에서 Google로 처음 시작하는 경우를 지원한다. 양쪽 계정에 이미 여행 기록이나 구매 이력이 있는 경우의 병합은 후속 범위다.

## 확인할 항목

- 로그인 중 앱을 닫았다 열어도 초대와 기기에 저장한 초안을 이어갈 수 있는지 검증한다.
- 기기 이전 후 기존 구성원 권한과 확정 송금표를 그대로 조회할 수 있는지, 승인 실패 시 기존 계정과 데이터가 유지되는지 검증한다.
- 복구 이메일을 운영에서 사용하기 전에 발송 서비스를 연결하고 코드 수신을 검증한다. 발송 서비스는 출시 준비에서 결정한다. 계정 삭제는 앱과 웹에서 시작할 수 있도록 설계한다. [Apple 계정 삭제 안내](https://developer.apple.com/go/?id=ar-ad-support) · [Google Play 계정 삭제 안내](https://support.google.com/googleplay/android-developer/answer/13327111)

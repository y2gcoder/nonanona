# 원화 환산 기준

상태: accepted (2026-11-21)

합의일은 2026년 11월 21일이다. 첫 버전에서 원본 금액과 통화를 보존하고, 송금표는 원화(KRW)로 만든다. 환산 금액을 자동으로 채워 영수증마다 환율을 입력하는 일을 줄이고, 방장이 필요한 항목을 수정할 수 있게 한다.

## 원화 환산 우선순위

1. **확정된 실제 원화 결제액**을 우선 사용한다. 이미 원화로 결제했거나 카드·계좌에 원화 청구액이 확정된 경우 그 금액을 적용한다. 여러 사람이 결제했다면 각 결제자의 실제 금액을 적용한다.
2. **증빙으로 확인한 외화 취득 원가**를 사용한다. 엔화 잔액으로 결제했거나 현금을 썼고 해당 엔화를 마련하는 데 든 원화 금액을 확인할 수 있으면 그 금액에서 환율을 구한다. 같은 결제자가 같은 기준으로 마련한 엔화는 환율을 한 번 입력해 관련 지출에 적용할 수 있다.
3. **지출일의 기준환율**로 자동 환산한다. 실제 원화액과 외화 취득 원가를 확인할 수 없으면 이 금액을 예상 금액으로 표시한다. 방장은 확인 후 실제 원화액으로 바꿀 수 있다.

## 예상 금액, 보류, 확정

- 지출 자체가 확인됐고 환율만 추정했다면 예상 금액과 적용 기준일을 표시한다. 방장이 금액을 확인하면 정산에 포함할 수 있다.
- 실제 결제 여부나 지출 금액이 불명확하거나, 최종 청구액 확인을 기다리거나, 같은 지출일 가능성이 있는 항목은 사유와 함께 보류한다. 보류 항목은 최종 송금액에서 제외하고, 방장이 확인한 후 포함할 수 있다.
- 항공권 결제 메일·숙소 예약 화면·카드 내역이 같은 결제를 가리키면 여러 증빙을 지출 한 건에 연결한다. 예약 화면만으로 선결제와 현장 결제가 구분되지 않으면 결제 내역을 확인한다.
- 정산을 확정할 때 적용한 원화 금액과 환율을 고정해, 이후 기준환율이 바뀌어도 같은 송금표를 재현할 수 있게 한다.

## 현금과 ATM 인출

- ATM 인출액은 현금을 마련한 기록으로 다룬다. 공동 정산에는 실제로 함께 쓴 현금만 포함하고, 이미 지출로 기록한 금액에 인출 원금을 다시 더하지 않는다. 남은 현금과 개인 사용분은 공동 지출에서 제외한다.
- 토스 외화통장에서 엔화가 출금된 경우 인출 내역은 엔화 출금의 근거로 쓴다. 원화 취득 원가는 환전 내역의 원화 출금액과 엔화 입금액에서 확인한다. 원화통장에서 직접 출금된 경우 확정 원화 출금액과 실제 받은 엔화를 대조한다. 두 경우 모두 출금액에 이미 포함된 수수료는 한 번만 반영한다.
- 예를 들어 95,000원에 10,000엔을 마련하고 그중 8,000엔을 공동으로 썼다면 공동 지출은 76,000원이다. 두 명이 균등 분담하고 한 명이 모두 냈다면 다른 사람이 선결제자에게 38,000원을 보낸다.

## 미정

- 토스 앱의 거래 상세 화면에 실제로 표시되는 원화·엔화 항목과 환전 증빙 발급 가능 여부
- 기준환율의 데이터 제공처, 미공표일 처리, 환산액의 원 단위 반올림. 엔화는 [ADR-0008](0008-jpy-reference-rate.md)에서 정했다(한국은행 ECOS 731Y001 원/일본엔(100엔), 지출일 또는 그 전 가장 최근 고시일, 지출마다 정확한 계산 뒤 원 단위 반올림·양수 .5 올림, 방장 승인, "예상"으로 표시). 다른 통화는 아직 정하지 않았다. 잔여 원 배분은 확정된 원화를 두 사람이 반씩 나눌 때만 정했다([ADR-0007](0007-two-person-even-split.md): 홀수 금액은 결제자가 두 사람 중 한 명이면 1원을 더 부담한다). 세 명 이상과 결제자가 두 사람 밖인 경우는 아직 정하지 않았다.
- 여러 환전 건에서 마련한 현금을 섞어 쓴 경우의 처리와 확정 후 정정 방식
